# Userscripts

This directory contains userscripts I have made/modified that I use on my browser.

To install these, download the `.userscript.js` file and add them to your userscript manager, for example, in TamperMonkey, you can drag and drop files.

<img width="1422" height="678" alt="2026-06-07_14-14-21_1421x677" src="https://github.com/user-attachments/assets/db90d17e-36fb-402a-8f17-62a4ad18f20e" />

Some of these scripts may be uploaded onto [GreasyFork](https://greasyfork.org/en/users/1513745-zydezu), so please check that page for easier installation.

If scripts aren't working, ensure your browser is up-to-date.

<img width="636" height="296" alt="image" src="https://github.com/user-attachments/assets/707a42b0-caf9-4564-ad5f-c569799cbc0c" />
<img width="700" height="192" alt="image" src="https://github.com/user-attachments/assets/517a36ff-c0f5-4ff9-9f23-ffc850b2fdf8" />

On Chromium-based browsers, ensure that developer mode is enabled on the extensions page, and also under the Tampermonkey extension options, that "Allow user scripts" is on, along with "Site access" set to "On all sites" as shown in the images above.
